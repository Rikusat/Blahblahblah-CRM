# 🎯 開発目的

現在、Googleスプレッドシートで営業リストを管理しています。
このスプレッドシートをそのままデータベースとして利用し、
Salesforceのような高機能・高コスト・複雑なCRMではなく、

- シンプル
- 直感的
- 必要な機能だけを追加できる
- Pythonで自由に拡張可能
- Streamlit Cloudで簡単に運用可能

という特徴を持つ、軽量CRMを構築したいです。

---

# 💡 コンセプト

「Googleスプレッドシートをそのまま使える、
個人・中小企業向けのミニCRM」

特徴：

- Googleスプレッドシートをデータベースとして利用
- カラム追加に自動対応
- Pythonで自由に機能追加可能
- Streamlit Cloudで無料または低コスト運用
- Salesforceほど複雑ではなく、必要な機能だけを順次追加できる

# 🎯 最初のリリースで重視すること

このアプリは「まず動くこと」を最優先とします。

そのため、

- 複雑な設定画面は作らない
- 高度な権限管理は行わない
- 後から簡単に機能追加できる構造にする
- 最小限のコードで使い始められるようにする

という方針で設計してください。

# 🔁 必須機能（MVP）

## 1. Googleスプレッドシートをデータベースとして利用
- gspread または Google Sheets API を使用
- 読み込み・更新・追加・削除に対応

## 2. カラム追加への自動対応
- スプレッドシートの1行目（ヘッダー）を動的に取得
- 新しい列を追加してもコード変更なしで対応
- DataFrame.columns を基準に画面を生成

## 3. 顧客一覧表示
- テーブル表示
- キーワード検索
- 業種フィルタ
- 任意の列で絞り込み可能

## 4. 顧客詳細編集
- レコード選択
- 全カラムを自動的にフォーム生成
- 編集後に保存

## 5. 新規登録
- 全カラムを入力して追加

## 6. 削除
- 選択した顧客を削除

## 7. 簡易ダッシュボード
- 総件数
- 業種別件数
- メール送信済み件数

## 8. 簡易認証
- パスワード認証のみ
- Streamlit secrets で管理

# 🔄 動的フォーム生成

DataFrame.columns をループして、すべてのカラムに対して入力フォームを自動生成してください。

列名に応じてUIを切り替える設計にしてください。

例：
- 備考 → text_area
- その他 → text_input

これにより、新しい列をスプレッドシートに追加しても、そのままフォームに反映されるようにしてください。
